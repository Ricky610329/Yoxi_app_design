# 遊喜樂 — 獨特優勢與差異化

> **回答簡報哪幾頁**：第 5 章「獨特優勢與差異化」（比較表一頁、難以複製的三件事一頁）；評審問答備用頁（三個必問）；第 3 章流程頁挑截圖時的「會讓人停下來的 5 個點」。
> **結論三句**：① 走路收集、存地點、點數回饋各自都有人做，但「探索行為 → 叫車訂單 → 和泰 Points 跨集團回流」這條迴路只有和泰有。② 我們把「走得到就別叫車」寫進按鈕（3 km 門檻），這是叫車平台自己不會做的節制，也是遊喜樂不被讀成廣告的原因。③ 「叫車沒變難用」是一個指令可以重跑的六條數字，不是口號；別家要複製畫面容易，要複製這套紀律難。
> **還沒有答案的事**：使用者是否真的會為「一天一個地方」回來（沒有使用者研究數據，靠 pilot 驗）；LINE POINTS 也能跨 LINE 生態系使用，我們的「跨集團」論點要講清楚是「跨出行與用車」而不是「只有我們能跨」；地方政府觀光 app 的完整盤點沒有做，下表那一列部分是假設。

## 2. 難以複製的三件事

### 2.1 探索行為 → 叫車訂單 → 和泰 Points 跨集團回流

| 項目 | 內容 |
|---|---|
| 迴路 | 探索（今天的地方、路線）→ 走不到的一段「設為下車點」→ 叫車 → 抵達解鎖（3 km 外；原型固定 +50，建議版依距離 20／35／50 點）→ 和泰 Points → 折抵 yoxi 車資、iRent 租車、HOTAI 購、汽車保養 |
| 可查證的事實 | 和泰 Points 1 點 = 1 元，可折抵 yoxi 車資（單趟最高 50 元）、兌換搭車金、HOTAI 購消費（[yoxi 官方](https://www.yoxi.app/promotion/984)）；TOYOTA、LEXUS、HINO、yoxi、iRent、HOTAI 購都可使用（[SUPER POINT 整理](https://blog.superpoint.com.tw/%E6%97%85%E9%81%8A|%E4%BA%A4%E9%80%9A/a4ace13b-6a5c-4f97-b1ce-bf23f323c072)） |
| 原型裡看得到 | `/points`：搭車回饋（$691 ÷ 20 捨去 = 34 點）與遊喜樂解鎖回饋（+50）分列，總數 = 明細相加（`points.png`） |
| 為什麼別家不會做／做不到 | **Google、Niantic**：沒有車隊，探索的終點是地圖導航，接不到自己的訂單。**LINE GO**：LINE POINTS 能跨 LINE 購物與支付，但不接用車、租車、保養；它的迴路是「消費」，不是「出行」。**Uber**：點數限 Uber 內、60 天失效、綁月費。**和泰**：同一集團有叫車、租車、車廠、保養、商城，探索行為產生的點數在出行這條鏈上都用得到——這條鏈別家拼不出來 |
| 誠實的但書 | +50 由誰付還沒簽核（`business.md` 建議試辦由 yoxi 行銷預算出、第二季起合作地點由合作方分攤一半；`roadmap.md` R4）；「跨集團」不是和泰獨有的概念，獨有的是「跨出行與用車」 |

### 2.2 「走得到就別叫車」寫進按鈕（3 km 門檻）

| 項目 | 內容 |
|---|---|
| 設計 | 地方詳情的主按鈕依距離切換：3 km 內是「走路前往」、3 km 外才是「設為下車點 · 約 $691 · 65 分」；+50 點與金框只給 3 km 以外的地方（`app/js/app.js` `WALK_MAX_M: 3000`、`ride.js` `limitedPlace`） |
| 原型裡看得到 | 玻璃窯 900 m：主鈕是走路（`place.png`）；內灣 28 km：主鈕是叫車（`place-far.png`）；路線上「腳到不了的一段」才出現叫車（`route.png`） |
| 為什麼別家不會做 | 叫車平台的 KPI 是訂單數，每一個地點都想放一顆叫車鈕（我們試過：變體 K2 每張地圖小卡兩顆按鈕、K3 下雨推播帶車，都沒選）。主動叫使用者「走路就好」是反直覺的 |
| 為什麼這對 yoxi 反而好 | ① 遊喜樂不被讀成廣告，才撐得起「不搭車也打開」；② 補貼不會拿去買 900 m 的短程單（固定 +50 在 900 m、$95 的短程上等於退 53%，`business.md`）；③ 車出現的地方就是腳到不了的地方，理由最正當 |
| 驗證 | 按距離分組量「設為下車點」按下率（≤ 3 km／> 3 km）；K1 組 vs K7 組（整頁不提車）比每人總訂單 |

### 2.3 叫車沒變難用：可重跑的六條數字

## 3. 三個必問的標準回答

### 3.1 「為什麼不做在 LINE 上？」

1. 傳送本來就交給 LINE：週回顧、長輩圖的分享面板第一格就是「傳給家人」。
2. 遊喜樂做的是 LINE 做不到的那一步：把你這週真的去過的地方，自動做成一張可以傳的圖。
3. 更根本的是閉環：走不到的地方要變成一張 yoxi 訂單，點數要回到和泰 Points，這兩件事都在 yoxi 裡。
4. 做在 LINE 上，探索的終點是別人的叫車（LINE GO），點數回到別人的生態系。
5. 所以分工是：LINE 負責傳，yoxi 負責去過、到得了、回饋。

### 3.2 「跟 Google Maps 差在哪？」

1. Maps 回答「怎麼去你已經想去的地方」；遊喜樂回答「你每天路過的哪裡值得進去」。
2. Maps 的儲存是你自己存；遊喜樂是城市先開口，一天一個、附理由（天氣、時段、你還沒去過的那一類）。
3. 到了才上色：100 m 內停 1 分鐘才算去過，收下的不是座標，是「我去過」。
4. Maps 不會把你導向叫車；遊喜樂在走不到的地方一鍵填好下車點、車資當場算好。
5. 而且我們不碰你的完整行蹤：日誌、心情、走過的路線只有你看得到。

### 3.3 「這不就是集點？」

1. 集點有期限、有順序、有排名、有連續天數、有倒數；遊喜樂這五樣都沒有，而且寫成測試。
2. 獎章只寫「收集 4/8」，不做進度環；我們做過集點卡那一版（變體 X4 `?style=stamp`），刻意不選。
3. 點數只在搭車抵達 3 km 以外的地方才給，而且只出現在 Points 明細；走路去的地方只有明信片，沒有點數。
4. 好康任務原封不動、不同頁；我們也做過同頁版（變體 T1），證明合併會破壞它自己的語氣。
5. 動機來自地方的三段故事；如果訪談把「還沒有 X 類」讀成清單，回頭看條件已寫好：退回一天一個。

### 3.4 三個必問的第二層追問

| 第一問 | 最可能的追問 | 回答（一句） | 出處 |
|---|---|---|---|
| 為什麼不做在 LINE 上 | 「LINE POINTS 也能跨很多服務，你的點數哪裡特別？」 | LINE POINTS 跨的是消費；和泰 Points 跨的是出行與用車（yoxi、iRent、保養），探索行為產生的點數正好回到下一次出行 | [yoxi 官方](https://www.yoxi.app/promotion/984) |
| 為什麼不做在 LINE 上 | 「那長輩圖為什麼不直接做成 LINE 貼圖？」 | 長輩圖的內容是你這週真的去過的地方，資料在 yoxi；傳送仍然走 LINE | `generation.md` Q2 |
| 跟 Google Maps 差在哪 | 「Google 加一個『今天推薦』就追上了？」 | 推薦可以追，接上自己的叫車訂單與點數追不了；Maps 不會把使用者導向單一叫車品牌 | §2.4 |
| 跟 Google Maps 差在哪 | 「你們的地圖是不是比 Google 差？」 | 是，底圖是 OpenStreetMap（ODbL，須署名）；我們不跟 Maps 比地圖，比的是誰先開口 | `prototype/assets/map/` |
| 這不就是集點 | 「那 +50 點不就是集點誘因？」 | 點數只給 3 km 以外、真的搭車抵達的地方（建議版依距離 20／35／50 點、每人每月最多 4 次），是給遠方的理由；900 m 的地方不給，因為那會把走路換成短程單 | `ride.js` `limitedPlace`、`business.md` |
| 這不就是集點 | 「收集 3/4 不就是進度條？」 | 是一個分數，沒有期限、沒有順序、沒有獎勵在 4/4 等你；訪談若被讀成清單就退回一天一個 | `catalog.js` AXES explore |

## 5. 我們刻意不做的

| 不做 | 業界常見的理由 | 我們的商業理由 | 證據（原型裡） |
|---|---|---|---|
| 聊天 | 提高黏著、社群感 | 聊天要審核、要客服、要處理騷擾，成本落在 yoxi；而且把叫車 app 變成社群 app，偏離「城市移動與生活的夥伴」 | 好友概念稿沒有聊天，只寄明信片（`concept-friend-send.html`） |
| 排名 | 刺激比較、提高頻率 | 排名獎勵的是頻率而不是地方，會催出假打卡；也讓長輩、偶爾出門的人一打開就是輸家 | 沒有任何排行畫面；禁用詞測試 |
| 連續天數 | 留存工具的標配 | 斷一天就流失；而且逼人「為了不斷」出門，跟「一天一個、沒有期限」衝突 | 變體 X5 步數成長條最接近 streak，不選 |
| 倒數 | 製造急迫 | 急迫感讓遊喜樂變成促銷；玻璃窯要整修也只說「現在還看得到」 | 文案規則（`emotion.md`「不該說的話」） |
| 限量 | 稀缺感 | 跟「明信片不會消失」衝突；「限定版」字眼也要改成「搭 yoxi 抵達版」 | `business.md` 第一次檢討 5 |
| 未讀數字 | 拉回開啟 | 紅點與數字是焦慮，不是理由；推播一天最多兩則已經是上限 | `business.md` 建議拿掉探索 tab 的紅點 |
| 好友（先不做） | 社群擴散 | 五問還沒答完（AI 鄰居該不該回信、能不能寄給沒裝 app 的人、「回一張」要不要做成按鈕、20 字是不是太多、入口放哪）；沒想清楚的東西不進 app | `prototype/boards/board-friends.html` |

**一句話**：我們不做的每一樣，都是會讓「不搭車也打開」看起來數字變好、但讓 yoxi 的品牌與客服成本變差的東西。
