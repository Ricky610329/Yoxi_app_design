# 撰稿與驗證紀錄

日期：2026-09-29。範圍：`pitch/writing/` 的 Markdown 提案文件及 HTML 閱讀版；未修改 App、原型、簡報或影片。

## 文件檢查

- 核對相對連結、引用圖片存在、Markdown 程式區塊成對，以及專案用語規範。
- Markdown 階段人工檢閱 Mermaid 的節點、資料流與責任邊界；HTML 階段另提供本機 SVG 圖面，不載入 Mermaid 執行套件。
- 實際查看補充資料引用的叫車卡片、取得卡片、圖鑑畫面；標示為現有原型證據，未宣稱已接正式叫車、定位或 LINE 服務。
- 以官方文件核對 AI 標價、模型能力、Expo 開發與 brownfield 限制、LINE 分享及事件範圍。來源和查詢日期列在 [補充資料](08-references-and-evidence.md)。價格仍須在採購時重查。
- 以十進位運算覆核 [成本文件](04-cost-and-resources.md) 的公式；美元呈現至小數第二位。人力、內容量、匯率、token 用量與處理時間均屬假設。

重點試算：5 款圖面初期模型費 US$36.91、每月 US$12.30；混合參考影像模型情境初期 US$44.20、每月 US$14.73，另計輸入影像及重試；每月內容文字模型費 US$3.26；個人化文字範例 US$31.55；最小試點介接 240–384 人時。這些是不同費用項目或替代情境，不能直接視為完整服務總價。

## 原型回歸

共同工作區另有開發中的修改，因此在獨立工作樹及 `docs/competition-writing-scope` 分支驗證，程式基準為 `6b1ae4f`。撰稿前後皆執行：

```powershell
python prototype/tools/verify-quiet.py
```

兩次皆取得八段完整結果：幾何、DOM、結構、互動、全站、圍牆、樹、功能數。沒有 FAIL 或缺少瀏覽器結果；六條承諾數值與基準相同。全份報告的內容一致，僅一項全站數字檢查的輸出順序不同。

基準中 E、F 變體本來就有 3、39 處 DOM 差異，兩次相同；腳本判定通過不代表所有變體與主畫面完全一致。檢查過程產生的 `prototype/assets/load.js`、`load.json` 不屬於本次文件交付，未納入提交。

這項結果驗證的是文件工作樹內的固定程式基準，不涵蓋共同工作區後續或同時進行的 App 改版。此次沒有建置 Expo App、執行正式叫車、發送 LINE 訊息或部署雲端服務。

## 交接時須保留的區分

- 現有 HTML／Web App 與離線生成圖面，是可查看的概念證據。
- Expo 是獨立手機示範的候選工具；是否整合既有 yoxi App，要由企業依現有技術與串接條件決定。
- 去程、候車待命、回程的正式供給、費率與 API 尚待企業確認。
- LINE 分享入口與自建家庭回應頁分開描述，不宣稱可讀取私人聊天室的按讚或留言。
- 抵達取得卡片及里程碑使用固定規則；機率抽卡與抽獎討論只保留在備存文件，不列為本次主方案。
- 低額模型費不等於服務零成本；人工審核、工程介接、定位驗證、資料庫、分享成品與維運須分列。

## HTML 閱讀版檢查

- 入口：[index.html](index.html)。八份 Markdown 轉為單頁文件，五張圖改用本機 SVG；早期討論預設折疊，列印時略過。
- Chrome 以 1440 px 桌面及 390 px 手機視窗檢查：正文無水平溢出，放大字體後仍無溢出；31 個表格保留資料，手機可在表格內左右捲動。
- 測試章節跳轉、目錄高亮、字體切換、備存展開與列印按鈕呼叫；圖片皆載入，沒有外部資源請求。檢查本機連結與章節錨點有效。
- 實際查看桌面封面、章節、手機版及五張 SVG 全圖截圖，確認標籤和箭頭無裁切。列印按鈕已驗證呼叫瀏覽器列印，未宣稱輸出的 PDF 已逐頁校對。
- SVG 生成器核對原始 Mermaid 雜湊與產出檔案；來源改變會要求同步檢閱圖面，不會沿用舊圖。
- HTML 工作前後另跑兩次原型驗收，皆八段通過；報告內容與六條承諾數值一致。驗證仍限同一獨立工作樹的程式基準。

重跑方式見 [維護說明](tools/README.md)，瀏覽器檢查執行 `python pitch/writing/tools/check-reader.py`。截圖與 JSON 報告寫入系統暫存目錄，不納入正文交件。
