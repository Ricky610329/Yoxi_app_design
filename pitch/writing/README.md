## 文件怎麼讀

每份先提供可摘入簡報的正文，再列圖表、工程細節與估算。架構圖與流程圖使用 Mermaid。補充資料包含 GitHub 入口、程式文件及現有畫面，相對連結可從專案內直接查看。

「保證取得」指符合公開收錄條件的到訪一定可留下卡片；不代表定位錯誤時必須立刻核發、不代表需即時呼叫 AI。圖片可預先生成並審核，到訪時組合日期、款式與紀念標記，形成當次專屬成品。

## 現況與提案界線

| 標示 | 含義 |
|---|---|
| 已實作／模擬 | repo 具有畫面、規則、素材或演示行程；不表示已串接企業服務 |
