# 五種敘述方向

同一個 app，對不同的人要用不同的說法。五份稿子各自有：一句話、一段話、30 秒版、對應 app 真實按法的 3 分鐘 demo 講稿、
五題質疑與回答、適合對誰講與不該說的話、十句可直接複用的句子。全部守產品性格：沒有任務／打卡／排名／倒數的字。

| 檔 | 方向 | 一句話 | 講稿主幹 | 對誰講 |
|---|---|---|---|---|
| [`emotion.md`](emotion.md) | 情感／城市探索 | 把每天路過的城市，走進去一次。 | A 流程（推播 → 今天的地方 → 走路 → 解鎖 → 收藏） | 設計評審、品牌、一般聽眾 |
| [`conversion.md`](conversion.md) | 商業轉換 | 不搭車的日子，替搭車的日子養訂單。 | B 流程（路線 → 內灣 → 設為下車點 → 叫車 → 限定版 → 點數） | yoxi 業務與產品、投資人 |
| [`zero-harm.md`](zero-harm.md) | 零傷害／可驗證的承諾 | 叫車沒變難用，每一條都能當場重跑。 | 先看叫車首頁與現況一樣 → 跑驗收 → 再走 B | 工程與產品主管 |
| [`generation.md`](generation.md) | 世代／家人 | 同一批明信片，換個排版給爸媽。 | C 流程（晚上推播 → 回顧 → 日誌只有你 → 週回顧 → 長輩圖） | ESG、公共關係、敬老愛心車隊相關 |
| [`city.md`](city.md) | 城市公共價值 | yoxi 載人穿過城市，也把地方接回來。 | 探索地圖（真實新竹）→ 路線 → 地方故事 → 城市足跡 | 地方政府、文化與觀光單位、在地合作方 |

## 怎麼搭

- 8 分鐘提案：評審視角（`../webapp-review/judge.md`）建議 **B 流程放第一**，用 `conversion.md` 的講稿開場，
  中段換 `emotion.md` 的 A 流程講「不搭車也會打開」，收尾用 `generation.md` 的長輩圖給溫度。
- 對 yoxi 內部：`zero-harm.md` 先講、`conversion.md` 後講；承諾要說清楚適用在原型還是合一版（合一版只有「4 顆景點」有 app 測試）。
- 對地方單位：只用 `city.md`，並把內容供給的三種模式表拿出來談。

## 數字怎麼引用

講稿裡的車資、分鐘、點數都是 app 當場算的（`75＋22×km`、`3＋2.2×km` 分、搭車回饋每 20 元 1 點無條件捨去、走不到的地方搭車抵達另 +50）。
demo 前先按「重設 demo」，數字才會跟稿子一致；不確定就講「以畫面為準」。
