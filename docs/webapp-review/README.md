## 五份都點到的事

1. **六條防護承諾量的是原型，不是 app。** 合一版的 `/ride` 動了 tab bar、常駐 4 顆景點、banner 第一格；app 的測試裡只有「剛好 4 顆」有斷言。
   講的時候要說清楚承諾適用在哪一版（`docs/narratives/zero-harm.md` 已照這個寫）。下一步：把②tap 數、③收合態、⑤不遮 pin、⑥兩套標記搬進 `app/tests`。
2. **內容供給沒有證據。** 22 張卡、7 個有座標的真實地點、四個虛構地點；擴一個城市就是一條內容產線。`docs/narratives/city.md` 給了三種供給模式的取捨表，成本仍是「待估」。
3. **計數感。** 勳章牆、收集 n/m、足跡百分比、+50 同框，加起來就像集點。UX 與評審都認為 AI 明信片＋勳章牆是最像 gimmick 的部分。
4. **對比與尺寸。** 次要文字用 slate 灰不到 4.5:1；關閉鍵 34×34。

- 評審／QA：內灣頁兩個分鐘數、清除足跡真的清空、1280×720 投影縮放、行程中不能改下車點、週回顧數字不倒退且標題日期對得上。
