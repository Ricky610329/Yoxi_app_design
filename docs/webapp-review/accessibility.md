# 無障礙與高齡使用者評審（web app 合一版）

評審角度：WCAG 2.2 AA 對照＋高齡使用者。長輩在這個提案裡同時是收件人（長輩圖）與可能的使用者。

## 三句結論

1. 結構底子不差：按鈕都是原生 `a`／`button`（Enter 可觸發、沒有正值 tabindex），293 個可按元素只有 1 個沒有名稱，`prefers-reduced-motion` 與 `?still=1` 都有接好。
2. 真正卡住長輩的是「看不清、點不準」：次要文字 slate 在白／mist 底只有 3.09–3.53:1，量到的文字元素 30% 小於 12px，叫車首頁最重要的「要去哪裡？」只有 1.63:1，關閉鍵 34×34 出現在 11 個畫面。
3. 長輩圖的大字排版方向正確，但它現在只是一張畫面上的卡片：沒有匯出成圖、沒有收件端設計，字的對比也看底圖運氣（金色字對天空只有 3.05:1）。

## 問題

### 阻斷

- **`/ride` `.route-input__value--ph`「要去哪裡？」** → 1.63:1，近乎看不見，而它是叫車唯一入口 → 低視力、長輩 → 改用 slate（3.53）以上，最好用 `--yoxi-navy-60`（白底 4.44）或更深。
- **`APP.ui.confirm`（`.app-confirm`）與分享面板 `.sys-share`** → 開啟後焦點留在 body、沒有 Esc、沒有把焦點圈在框內；「清除足跡」這個不能復原的確認框也一樣 → 螢幕閱讀器使用者找不到「清除／先不要」 → 開啟時 `focus()` 到「先不要」，Esc＝取消，關閉後把焦點還給觸發鍵。

### 嚴重

- **全站 slate 次要文字**（`.row-nav__sub`、`.ai-note`、`.badge__prog`、`.alb-foot`、`.ex-muted`…）→ 3.03–3.53:1 → 長輩、戶外強光 → 見下節第 1 點。
- **11px 字**（tab 標籤、`.statbar__k`、`.postcard__name`、`.ex-eyebrow`、`.badge__name`）與 9px 的 AI 標記 → 長輩讀不到；統計列是「11px＋3.03:1」雙重不過。
- **小關閉／離開鍵**：`.hdr-red__close` 34×34（11 頁）、`.ride-back` 32×33、`/lookback .alb-lb__exit` 42×22、`/explore [data-act=open-routes]` 58×20、`/trip [data-act=cancel-trip]` 76×27 → 手抖、按不準 → 用 `::after` 往外擴到 44×44，外觀不變。
- **`.banner--gold` 與 `yoxi 限定版` 角標** 白字／金 2.42 → 改海軍藍字（6.74）。
- **`/dropoff` 搜尋框** → 沒有 label、`outline:none` → 加 `aria-label`，焦點改用底線或 box-shadow。
- **標題階層**：`/dropoff`、`/pickup`、`/drawer`、`/going`、`/unlock`、`/footprint`、`/lookback` 沒有 h1；`/postcard`、`/badge` 頁首與內容各一個 h1 → 用標題跳讀的人迷路。
- **資訊性圖沒有文字**：`/week` 三張 117px 圖表、`/footprint` 霧地圖（覆蓋率只在圖上）、`/route` 路線圖 → 加 `role="img"`＋一句 aria-label（例「這一週走了 23.6 公里，比上週多…」，數字從公式帶入）。
- **toast** 沒有 `role="status"`，2.4 秒消失；「已傳給家人」「連結已複製」這種確認只出現在 toast → 加 live region、重要訊息延到 4 秒。

### 建議

- `/ride` sheet 把手只吃 pointer：加一顆 `button` 包把手（`aria-expanded`），鍵盤與讀屏才打得開。
- 換頁後焦點不動：`data-view-ready` 時把焦點移到新畫面的 h1（`tabindex="-1"`）。
- tab bar `nav` 沒有 aria-label；探索上的紅點沒有文字 → 加隱藏文字「有今天的地方」。
- 「灰色＝還沒去」：收藏書架有鎖頭＋淡名字，但探索的 `.ex-chip__img`、`.ex-row__img`、peek 只靠灰階 → 每張灰圖旁加「還沒去」三個字。
- 推播浮層 `.sys-push` 出現時沒有 role 也不搶焦點 → 至少 `role="dialog"` 並聚焦卡片。

## 高齡使用者的 5 個具體改法（便宜、不動設計紀律）

1. **次要文字加深，不加新色票**：在 app 層用 `color-mix(in srgb, var(--yoxi-slate) 70%, var(--yoxi-navy))`，量得 mist 4.85、白 5.54、cream 4.76，全過 4.5；不寫 hex、不動 `tokens.css`，六條承諾不受影響。
2. **設定頁加「大字」開關**：`html[data-bigtext]` 在 `app.css` 重新定義 `--fs-xs 11→14`、`--fs-cap 13→15`、`--fs-sm 14→16`；字級仍然只走變數。預設也建議把 tab 標籤從 11px 拉到 13px。
3. **可按範圍擴到 44×44、外觀不變**：關閉、返回、「先離開」「全部」「取消行程」用偽元素擴大點擊區，版面與可按數都不變。
4. **把「看得到才知道」改成「說出來」**：灰圖旁寫「還沒去」、toast 加 `role="status"` 並延長、確認框焦點落在「先不要」。清除足跡的「清除」鍵目前是實心海軍藍（主要動作樣式），改成外框樣式，讓「先不要」看起來是安全的預設。
5. **手勢一律有鈕**：sheet 把手變按鈕；翻面已有「翻面」鍵、onboarding 已有「下一張／略過」、地圖已有「回到你的位置」與卡片清單，這幾個保留並在文案裡點名（例：「點這裡翻到背面」）。

## 長輩圖與家人分享

- **字級**：大字 30px 佔圖寬 8.4%；貼到 LINE 泡泡（約 240px 寬）約 20px，長輩讀得到。日期地點那行 16px 會縮到約 11px，署名 11px 縮到約 7px。建議日期地點行放大到 20px 以上。
- **對比**：全圖只蓋 18% 黑，字後面的天空亮度每張不同；這張金字對天空 3.05、白字對最亮處 2.44。改成字後面一條半透明深色帶，對比就不看底圖。
- **收件端沒有 app**：現在「傳給家人」只跳 toast，沒有產生圖檔；「複製連結」寫「對方點開只看得到這一張」，但那一頁不存在。長輩那一端最穩的是**一張普通 JPG 直接進 LINE**，地點與日期已經在圖上，所以不需要 alt；不要讓長輩點連結開網頁。
- **會不會像被監看**：不會。內容是傳送者自己說「我今天去走走了」，而且「只有你按下傳送才會送出」寫得很清楚；分享面板也沒有家人模式、沒有位置共享。風險在反方向：如果長輩自己是使用者，「長輩圖」這個詞當成選項說明（「自動排成長輩圖」）有點把人分類，建議改寫「大字圖卡，適合傳到家族群組」。

## 認知負擔

- **可按數 ≤ 10**：對長輩整體是幫助，一屏選項少、主要動作清楚。但它把兩件事藏起來了：叫車鈕在沒填下車點時是 `data-expand-only`（得先展開 sheet 或先填下車點才看得到），城市足跡入口是 96×25 的頁首小字。建議守住「≤ 10」的同時，讓被收起的入口留一行看得到的文字提示，而不是只靠拖曳。
- **三分頁名稱**：「叫車」直覺；「收藏」可懂；「探索」對長輩偏抽象，容易理解成「搜尋」。不必改名，第一次進探索時用一句話說明「附近值得走走的地方」即可。這一點沒有做使用者測試，屬於判斷不是量測。
