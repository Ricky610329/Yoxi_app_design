| 圖片 | 用途／最後決定 |
|---|---|

| [雙主頁腦力激盪](yoxi-two-page-brainstorm.png) | 使用者的早期草圖：叫車與收藏兩個底欄入口、探索上拉、卡片疊放等想法；圖上的文案及其他功能尚未全部採用。 |
